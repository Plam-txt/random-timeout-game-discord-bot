# random-timeout-game-discord-bot
timeout people just for fun

# USING AND BUILDING

create the your bot in [Discord Developer portal](https://discord.com/developers/home) first then get the token in OAuth2
then create python file and install discord by using this on terminal 
`python3 -m pip install -U discord.py` ("if you are on window")
then put token on `bot.run('PUT-TOKEN-ON-HERE');` at the bottom
and copy user id to `user_ids=[PUT-USER-ON-HERE]` ("it will be used to random people on the server")

after that click run and
using it write / and go to your bot and use the command
and give them administrater and drag role to upper every role
